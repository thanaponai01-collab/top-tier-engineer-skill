# INC-212: profile DB saturated (2026-04-13)

Dashboard page loads timed out from 09:40 to 11:15. The profile DB ran at 100% CPU.

Cause: every team dashboard view reads each member's profile individually, about 40 reads per view.
At peak that is about 9,000 reads/s against a DB sized for about 1,500. The 5 s profile cache barely
helped, because most views came from different teams.

Mitigation: raise the profile cache TTL from 5 s to 60 s (cuts reads by about 10x at our traffic).
Follow-up: batch the dashboard's profile reads (owner: Priya).
