# pantry

Keeps track of what's in the cupboard and what to buy next.

    python pantry.py list            # what's in stock
    python pantry.py shop            # what to buy
    python pantry.py scan            # add an item by scanning its barcode with the webcam
    python pantry.py serve           # the web app on http://127.0.0.1:8040

Your pantry lives in `pantry.json` (set `PANTRY_DB` to use another file).
